# @warpgogol/tokens

Canonical `--ds-*` CSS design tokens for the Warpgogol design system. Single source of truth for colors, typography, spacing, radius, shadows, motion, and z-index (Wave 6, RFC-0023).

## Purpose

All `--ds-*` custom properties are defined here. Apps and components must use these tokens instead of hardcoded values. The OS command `tokens.ds.lint` enforces this contract across all CSS files.

## Entry points

| Import                         | What it provides                                            |
| ------------------------------ | ----------------------------------------------------------- |
| `@warpgogol/tokens`            | TypeScript token name constants and type helpers            |
| `@warpgogol/tokens/tokens.css` | Raw CSS file with all `--ds-*` custom property declarations |

## Usage

### Import the CSS (in app global styles)

```css
@import "@warpgogol/tokens/tokens.css";
```

Or in `astro.config.mjs`:

```javascript
import tokens from "@warpgogol/tokens/tokens.css?url";
```

### Use tokens in component CSS

```css
.button {
  background-color: var(--ds-color-primary-500);
  border-radius: var(--ds-radius-md);
  font-size: var(--ds-font-size-base);
  box-shadow: var(--ds-shadow-md);
  transition: background-color var(--ds-motion-duration-fast) ease;
}
```

### TypeScript token constants

```typescript
import { DS_COLOR_PRIMARY_500, DS_RADIUS_MD } from "@warpgogol/tokens";
```

## Token categories

- **Colors** — `--ds-color-*` (primary, neutral, semantic palettes)
- **Typography** — `--ds-font-size-*`, `--ds-font-weight-*`, `--ds-line-height-*`
- **Spacing** — `--ds-space-*`
- **Radius** — `--ds-radius-*`
- **Shadows** — `--ds-shadow-*`
- **Motion** — `--ds-motion-duration-*`, `--ds-motion-easing-*`
- **Z-index** — `--ds-z-*`

## Constraints

- Do not declare `--ds-*` properties anywhere except this package.
- Biome-specific token overrides belong in `biome.yaml` and are generated by `biome.css.generate` — they must reference base `--ds-*` names, not hardcode values.

## Validation

```sh
pnpm --filter @warpgogol/tokens build:check
```
