# Currency Selector Component Content

Content template for the currency selector component (RFC-0743).

## Fields

- `label`: Accessible label for the currency selector dropdown
- `currencies`: Array of available currencies with `code` and `label`

## Example

```yaml
label: "Wahrung"
currencies:
  - code: "EUR"
    label: "EUR"
  - code: "UAH"
    label: "UAH"
  - code: "USD"
    label: "USD"
```
