# Chat Widget

Consent-gated, click-to-load chat launcher (RFC-0175). Renders a first-party launcher; the third-party chat vendor's script loads only after the visitor clicks. The vendor binding lives in `system.md integrations.chat`. Carries the in-widget legal notice + Privacy Policy link required by RFC-0177.
