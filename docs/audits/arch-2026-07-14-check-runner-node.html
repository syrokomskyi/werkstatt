Problem: captureSiteEvidenceGraph is a 60-line monolith mixing Playwright orchestration, screenshot I/O, evidence mapping, and graph finalization — untestable without a real browser.

Solution: Extract a BrowserCapturePort interface (launch, navigate, evaluate, screenshot); the Playwright adapter implements it; captureSiteEvidenceGraph orchestrates the port + pure assembly.

  • locality: Playwright coupling in one adapter
  • leverage: mock adapter enables unit tests
  • depth: orchestration interface is narrow
