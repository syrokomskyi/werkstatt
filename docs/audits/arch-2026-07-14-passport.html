Replace hand-rolled base58 with an audited library

Problem: toBase58 and fromBase58 are 40 lines of hand-rolled BigInt arithmetic for base58btc encoding — a security-sensitive cryptographic encoding that should not be reimplemented.

Solution: Use the multiformats package (or bs58) for base58btc encode/decode; toMultibase/fromMultibase become one-liners wrapping the library.

  • locality: crypto encoding in audited library
  • leverage: one dependency, no custom BigInt math
  • depth: sign.ts interface shrinks by 40 lines

Problem: emitPassport is a 108-line monolith performing 10 sequential steps inline — testing any step in isolation requires mocking the entire pipeline, and adding a step means editing the function body.

Solution: Introduce a PassportPipeline that composes ordered PipelineStep modules; emitPassport becomes a thin orchestrator that wires the default steps.

  • locality: each step in its own module
  • leverage: one pipeline interface, N steps
  • depth: emitPassport interface is one call
