Problem: createMetricsPusher is a 130-line factory that mixes env detection, metric validation, point accumulation, OTLP encoding, and HTTP transport (fetch + AbortController) — untestable without network mocks.

Solution: Extract an OtlpTransport interface (send(body): Promise<DeliveryResult>); HttpOtlpTransport wraps fetch; the pusher accumulates and validates, then delegates to the transport on flush().

  • locality: HTTP transport in one adapter
  • leverage: mock transport enables flush tests
  • depth: pusher interface is accumulate + flush

Extract env detection into a dedicated resolver module

Worth exploring in-process

Problem: getGlobalProcess, resolveEnv, and detectEnvironment are private functions in pusher.ts that poke globalThis.process — env detection logic is coupled to the pusher factory and not reusable.

Solution: Move them into a dedicated env-resolver.ts module; the pusher imports and calls resolveEnv(); other modules (e.g. conventions) can reuse the resolver.

  • locality: env detection in one module
  • leverage: one resolver, multiple consumers
  • depth: pusher.ts no longer owns env logic
