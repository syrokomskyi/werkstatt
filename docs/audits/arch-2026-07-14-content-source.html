Problem: index.ts re-exports both the pure port contracts and the filesystem adapter — consumers that only need the ContentSourceProvider interface transitively pull in the FS implementation and its node:fs dependency.

Solution: Split into /port (types only), /fs (filesystem adapter + asset resolver), and /astro (Astro collection loaders); index.ts re-exports only the port; consumers import the adapter they need.

  • locality: adapter and port in separate barrels
  • leverage: port consumers get no FS dependency
  • depth: index.ts interface shrinks to contracts
