Problem: TOKEN_NAMES is a 450-entry hand-typed tuple that must stay in sync with tokens.css — the tokens.catalog.sync command exists solely to catch drift between two copies of the same information.

Solution: Add a build step that parses tokens.css :root declarations and generates TOKEN_NAMES, DesignToken, and TOKEN_CATEGORIES automatically; the sync command becomes unnecessary.

  • locality: token names defined in one source
  • leverage: CSS is the single source of truth
  • depth: index.ts becomes a thin re-export

Top recommendation
