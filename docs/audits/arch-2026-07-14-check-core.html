Problem: findWorkspaceRoot does FS I/O via node:fs and process.cwd() inside a package whose stated purpose is schemas and pure logic.

Solution: Move findWorkspaceRoot into a separate workspace-resolver.ts module (or into check-runner-node), keeping run-paths.ts as pure posix path construction.

  • locality: FS concerns concentrate in one module
  • leverage: pure path helpers usable in Workers
  • depth: run-paths interface shrinks, no FS leak

Problem: Five collector functions each iterate the evidence graph independently — adding a rule means editing a function, and the graph is traversed N times.

Solution: Introduce a DiagnosticRule interface and a registry; collectDeterministicDiagnostics becomes a single-pass dispatcher over registered rules.

  • locality: each rule lives in its own module
  • leverage: one interface, N rules
  • depth: collector interface shrinks to one call
