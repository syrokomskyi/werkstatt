Problem: collectNebulaInputs does FS I/O via readJsonSafe with hardcoded filenames — untestable without real files on disk, and the four artifact paths are baked into the function body.

Solution: Introduce an ArtifactReader interface (read(kind): Promise<T>); a FilesystemArtifactReader implements it; collectNebulaInputs takes the reader as a parameter and becomes pure orchestration.

  • locality: FS I/O in one adapter
  • leverage: mock reader enables unit tests
  • depth: collector interface is pure assembly

Problem: computeNebulaScore hardcodes four derive calls and a pillarRawScores object — adding or replacing a pillar requires editing the function body and the weights module in lockstep.

Solution: Introduce a PillarStrategy interface (key, derive, weight); computeNebulaScore iterates a registry; weights and derive logic live together in each strategy.

  • locality: each pillar in one module
  • leverage: one compute interface, N pillars
