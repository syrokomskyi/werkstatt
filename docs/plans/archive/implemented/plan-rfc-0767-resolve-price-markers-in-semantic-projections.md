## 3. Step sequence

### Step 1. Create `price-marker-resolver.ts` and `derived-prices-loader.ts` in `packages/share/src/semantic/`

**Goal:** Create the new modules: pure functions/types in `price-marker-resolver.ts`, Node-only file loader in `derived-prices-loader.ts`.

**Agent actions:**

- Create `packages/share/src/semantic/price-marker-resolver.ts` (pure, no `node:fs`):
  - Export `DerivedPriceEntry` interface (copied from `packages/ui/src/sections/price-card/price-variants.ts:19-27`)
  - Export `OFFERING_URI_PREFIX` constant (`"https://warpgogol.com/id/offerings/"`)
  - Export `PRICE_MARKER_RE` regex (`/\{price:([a-zA-Z0-9_-]+):([a-zA-Z0-9_.-]+)\}/g`)
  - Implement `formatSourcePrice(amount: string, lang: string): string` — uses `Intl.NumberFormat` with `style: "currency"`, `currency: "EUR"`, `currencyDisplay: "narrowSymbol"`, `minimumFractionDigits: 0`, `maximumFractionDigits: 2`. Returns `"0\u00A0€"` for non-finite amounts. No recurrence suffix (unlike `formatPrice` in ui).
  - Implement `resolvePriceMarkersForSemantic(text: string, lang: string, derivedPrices?: Record<string, DerivedPriceEntry[]> | null): string` — replaces `{price:offering:chargeRef}` markers with `formatSourcePrice(entry.trace.source.amount, lang)`. Returns `"0\u00A0€"` for unknown offerings. Returns input unchanged if no markers. Handles `derivedPrices === null` or `undefined` by resolving all markers to `"0\u00A0€"`.
- Create `packages/share/src/semantic/derived-prices-loader.ts` (Node-only, imports `node:fs`):
  - Import `DerivedPriceEntry` from `./price-marker-resolver.ts`
  - Export `loadDerivedPrices(cwd?: string): Record<string, DerivedPriceEntry[]> | null` — reads `process.cwd()/src/derived-prices.generated.json`, returns `null` on ENOENT, throws on parse error (same behavior as existing `loadDerivedPrices` in `packages/ui`)

**Validation:**

- `pnpm --filter @warpgogol/share run build:check` passes with the new files

**Completion criterion:** Both files exist. `price-marker-resolver.ts` exports `DerivedPriceEntry`, `OFFERING_URI_PREFIX`, `PRICE_MARKER_RE`, `resolvePriceMarkersForSemantic`, `formatSourcePrice`. `derived-prices-loader.ts` exports `loadDerivedPrices`. `tsc --noEmit` passes.

**Human review:** no

### Step 6. Write unit tests

**Agent actions:**

## 5. Risks and mitigation

| Risk (from RFC) | Mitigation (plan step) |
| --- | --- |
| Semantic layer depends on derived prices file | Step 4: `reader.getDerivedPrices()` returns null on ENOENT; markers resolve to `"0\u00A0€"` — no crash |
| Cross-package type relocation breaks ui imports | Step 5: all imports updated in same change; `tsc --noEmit` validates both packages |
| Reader interface change breaks implementations | Step 3: both readers updated in same change; `tsc --noEmit` validates all three packages |
| `node:fs` pulled into client bundle | Step 2: `derived-prices-loader.ts` NOT exported from semantic barrel; subpath export only |
| Price format in JSON-LD is human-readable string | Accepted by RFC — existing `Offer` + `PriceSpecification` nodes provide structured data |
| Non-breaking space in output | Step 6: tests use `\u00A0` in expected values; `formatSourcePrice` documented to produce U+00A0 |

## 6. Escalation triggers

- If implementation reveals an invariant conflict with DNA-4, run `pnpm exec werkstatt run rfc.supersede.propose --id RFC-0767 --reason "..." --invariant "DNA-4"` instead of working around it.
- If `packages/ui` cannot import from `@warpgogol/share/semantic` due to pnpm strict isolation, add a subpath export before the import (Step 2 handles this).
