## 5. Risks and mitigation

| Risk (from RFC) | Mitigation (plan step) |
| --- | --- |
| Quality regression for content images | Step 4 adds `quality="max"` to all content image call sites before the default change takes effect |
| Manifest generation timing | Step 6 generates and commits the manifest; `image.variants.validate` confirms presence |
| Agent misinterpretation | The call-site audit table in the RFC is the authoritative reference; implementation notes instruct agents to follow it exactly |
| Cross-site impact | Steps 2 and 4 update all shared component call sites, so no site should experience visible degradation |
