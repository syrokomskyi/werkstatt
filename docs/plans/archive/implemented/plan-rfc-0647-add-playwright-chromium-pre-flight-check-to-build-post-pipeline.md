## 3. Step sequence

### Step 1. Create `playwright-chromium-ensure.ts` command handler

**Goal:** Create the new command handler module that extracts and generalizes the `ensurePlaywrightChromium` logic from `mission-materialize.ts`. Split into a pure function (`ensureChromium`) for direct reuse and a thin kernel handler (`runPlaywrightChromiumEnsure`) for pipeline/CLI use.

**Agent actions:**

- Create `packages/os/site-kernel-checks/src/playwright-chromium-ensure.ts`
- Implement `PlaywrightChromiumEnsureResult` interface: `{ installed: boolean; chromiumRevision: string | null; skipped: boolean }`
- Implement `ensureChromium(workspaceRoot: string, logger: { info: (msg: string) => void }): Promise<PlaywrightChromiumEnsureResult>` — pure function, no kernel types:
  - Check `PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD` env var — if set, skip auto-install
  - Check if Chromium is installed by attempting `chromium.launch({ headless: true })` (launch verification, not just directory check — matches `mission-check.ts:108-148` pattern)
  - If launch succeeds: return `{ installed: true, chromiumRevision: browser.version(), skipped: true }`
  - If launch fails and `PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD` is set: throw with message
  - If launch fails and env var not set: run `pnpm exec playwright install chromium` (120s timeout), then retry launch
  - If retry launch succeeds: return `{ installed: true, chromiumRevision: ..., skipped: false }`
  - If install or retry launch fails: throw with error message
- Implement `runPlaywrightChromiumEnsure(input, context): Promise<KernelCommandResult<PlaywrightChromiumEnsureResult>>` — thin kernel handler that calls `ensureChromium(context.workspaceRoot, context.logger)` and wraps the result in `KernelCommandResult` (catches errors → `exitCode: 1`)
- Add Compass MODULE_CONTRACT and CHANGE_SUMMARY headers
- Export both `ensureChromium` and `runPlaywrightChromiumEnsure`

**Validation:**

- `pnpm --filter @warpgogol/site-kernel-checks run build:check` — typecheck passes

**Completion criterion:** New file exists, typechecks, and exports `ensureChromium`, `runPlaywrightChromiumEnsure`, and `PlaywrightChromiumEnsureResult`.

**Human review:** no

### Step 4. Refactor `mission.materialize` to delegate to new command

**Goal:** Replace the inline `ensurePlaywrightChromium` function in `mission-materialize.ts` with a call to `ensureChromium` (pure function), preserving non-fatal behavior.

**Agent actions:**

- In `packages/os/site-kernel-handoff/src/mission/mission-materialize.ts`:
  - Remove the inline `ensurePlaywrightChromium` function (lines 563–597)
  - Add import of `ensureChromium` from `@warpgogol/site-kernel-checks` (pure function, not the kernel handler)
  - At the call site (line 928), replace `await ensurePlaywrightChromium(workspaceRoot, logger)` with:
    ```ts
    try {
      await ensureChromium(workspaceRoot, logger);
    } catch (err) {
      const msg = err instanceof Error ? err.message : String(err);
      logger.info(
        `  Playwright Chromium: ensure failed (non-fatal) — ${msg}. ` +
          `Run 'pnpm exec playwright install chromium' manually before build:check.`,
      );
    }
    ```
  - This preserves the existing non-fatal semantics: `mission.materialize` logs the error and continues

**Validation:**

- `pnpm --filter @warpgogol/site-kernel-handoff run build:check` — typecheck passes

**Completion criterion:** `ensurePlaywrightChromium` function removed from `mission-materialize.ts`; `ensureChromium` imported and called in try/catch.

### Step 5. Add unit tests

**Goal:** Cover the four key behaviors: skip when present, install when missing, fail on install error, respect env var.

**Agent actions:**

- Create `packages/os/site-kernel-checks/src/tests/playwright-chromium-ensure.test.ts`
- Mock `playwright` module via `vi.mock("playwright", ...)` — mock `chromium.launch` to simulate success/failure
- Mock `child_process.execSync` for install scenarios
- Test `ensureChromium` (pure function) directly, not the kernel handler
- Test cases:
  1. **Skip when present**: `chromium.launch` succeeds → result `{ installed: true, skipped: true, chromiumRevision: "..." }`, `exitCode` undefined
  2. **Install when missing**: `chromium.launch` fails first, `execSync` succeeds, `chromium.launch` succeeds on retry → result `{ installed: true, skipped: false }`
  3. **Fail on install error**: `chromium.launch` fails, `execSync` throws → `exitCode: 1`, error message contains "install failed"
  4. **Respect env var**: `PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1`, `chromium.launch` fails → `exitCode: 1`, no `execSync` call
  5. **Launch fails after install**: `chromium.launch` fails, `execSync` succeeds, `chromium.launch` fails on retry → `exitCode: 1`, error message contains "launch failed"
- Use `unknown` cast pattern for `data` field in test helpers (per memory: `result.data` is `unknown`)

**Validation:**

- `pnpm --filter @warpgogol/site-kernel-checks run test` — all tests pass

**Completion criterion:** 5 test cases pass, covering all 4 acceptance criteria behaviors.

## 5. Risks and mitigation

| --- | --- |
