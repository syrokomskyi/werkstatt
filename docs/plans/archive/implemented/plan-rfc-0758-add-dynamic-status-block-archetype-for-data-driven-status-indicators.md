### Step 4. Customize section template for composite body

**Goal:** Edit the scaffolded `.astro` template to render the data-driven status indicator (value + label + context) instead of the generic composite placeholder.

**Agent actions:**

- Edit `dynamic-status-block-section.astro`:
  - Import `SectionShell` and `SectionHeader` from `@warpgogol/ui/components/`
  - Import `need` and `cast` from `@warpgogol/share`
  - Destructure props: `value`, `label`, `contextText`, `valuePrefix`, `valueSuffix`, `valueTone`, `animated`
  - Render `<SectionShell>` with `data-animated="true"` when `animated` is true
  - Render `<SectionHeader>` with the section heading
  - Render the value in a `.dynamic-status-block__stat` element with `.js-stat-counter` span (for GSAP counter integration)
  - Apply `data-numeric`, `data-start` attributes to the counter span when `value` is numeric and `animated` is true
  - Render `valuePrefix` and `valueSuffix` in `.js-stat-prefix` / `.js-stat-suffix` spans
  - Render `contextText` below the value if present
  - Apply valueTone classes (`--value-tone-success`, `--value-tone-warning`, `--value-tone-muted`) to the value element via CSS custom properties
- Edit `dynamic-status-block-section.css`:
  - Add styles for `.dynamic-status-block__stat`, `.dynamic-status-block__value`, `.dynamic-status-block__label`, `.dynamic-status-block__context`
  - Use only `--ds-*` tokens
  - Add tone variants
- Edit `dynamic-status-block-section.story.md`:
  - Add a realistic example: open mandate count with `value: 1`, `label: "Відкритих мандатів"`, `animated: true`

**Validation:**

- `pnpm --filter @warpgogol/ui build:check` — typecheck passes

**Completion criterion:** Section template renders value/label/context with correct CSS classes and data attributes.

**Human review:** no
