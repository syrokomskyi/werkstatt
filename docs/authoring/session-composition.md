# Session composition

This document describes the session documentation domain conventions, metadata format, and shell wrapper instructions for the Warpgogol platform.

## Overview

Session transcripts are saved as structured markdown files under `docs/sessions/`. The domain provides four commands (`session.save`, `session.archive`, `session.validate`, `session.list`) and one skill (`fo-session-save`) for intelligent annotation.

## File layout

```
docs/sessions/
├── .raw/                    # Raw ATIF exports (gitignored)
│   └── 2026-07-26-session.atif
├── archive/                 # Archived sessions older than threshold
│   └── 2026-07-20-12-00-00-abcdef.md
├── 2026-07-26-12-04-00-a3f2c1.md  # Active session files
└── README.md                # Optional
```

## Session markdown format

```markdown
---
id: 2026-07-26-12-04-00-a3f2c1
date: 2026-07-26T12:04:00+02:00
duration: PT45M
types: [grilling, implementation]
summary: "Grilling session for session-save RFC, then implementation planning"
relatedRfcs: [RFC-0537]
relatedArtifacts: [packages/forge/os/session/session.module.ts]
decisions: ["Hybrid approach: command for deterministic, skill for intelligent"]
commits: [a3f2c1d]
files: [packages/forge/os/session/handlers/save.ts]
commands: [session.save, session.archive]
---

# Session: 2026-07-26-12-04-00-a3f2c1

## Transcript

[Full conversation transcript in markdown format, converted from ATIF]

## Session notes

[Skill-generated annotations: summary, decisions, related artifacts, quality checks]
```

The `## Transcript` section is generated by `session.save` (deterministic). The `## Session notes` section is generated by `fo-session-save` (intelligent). If the skill has not run, the `## Session notes` section is absent.

## Metadata fields

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | string | yes | `YYYY-MM-DD-HH-MM-SS-<6hex>` — timestamp + content hash |
| `date` | ISO 8601 | yes | Session start timestamp |
| `duration` | ISO 8601 duration | no | Session duration (e.g. `PT45M`) |
| `types` | string[] | yes | One or more of: `mission`, `grilling`, `implementation`, `review`, `fix`, `freeform` |
| `summary` | string | yes | 1-3 sentence summary (generated by `fo-session-save` skill) |
| `relatedRfcs` | string[] | yes | RFC-ids referenced in the session |
| `relatedArtifacts` | string[] | yes | File paths of artifacts created/modified |
| `decisions` | string[] | yes | Key decisions made during the session |
| `commits` | string[] | yes | Commit hashes (7-40 hex chars) |
| `files` | string[] | yes | File paths edited |
| `commands` | string[] | yes | Kernel commands run during the session |

## Commands

### `session.save`

Converts raw ATIF files from `docs/sessions/.raw/` to structured markdown in `docs/sessions/`. Auto-extracts metadata (RFC-ids, commit hashes, file paths, commands, session types) from the transcript.

- **Idempotent:** Same raw file always produces the same output filename. Skips if output already exists.
- **Raw deletion:** Deletes raw file after successful conversion unless `--keep-raw`.
- **Flags:** `--keep-raw`, `--dry-run`, `--json`, `--raw-file <path>`

### `session.archive`

Moves session files older than `--max-age-days` (default 7) to `docs/sessions/archive/`. Bidirectional — files in `archive/` younger than threshold are moved back.

- **Flags:** `--max-age-days <n>`, `--dry-run`, `--json`

### `session.validate`

Checks session files for:

- **SES-01:** Required frontmatter fields present (`id`, `date`, `types`)
- **SES-02:** `id` matches filename
- **SES-03:** `relatedRfcs` reference existing RFC files
- **SES-04:** No raw files left in `.raw/` (should have been processed)
- **SES-05:** No non-markdown files in `docs/sessions/` (excluding `.raw/`, `archive/`, `.gitkeep`, `README.md`)

### `session.list`

Lists all session files (active + archived) with filtering:

- `--date-from YYYY-MM-DD`, `--date-to YYYY-MM-DD`
- `--rfc RFC-NNNN`
- `--type <type>`
- `--json`

## Shell wrapper

`scripts/devin-export.sh` exports the current Devin CLI session as an ATIF file to `docs/sessions/.raw/`:

```bash
./scripts/devin-export.sh
```

After exporting, run `session.save` to convert the raw file to structured markdown:

```bash
pnpm exec site-kernel run session.save
```

### Windsurf (Cascade) sessions

Windsurf does not have a `devin --export` CLI equivalent. Instead, the `fo-session-retro` skill (Step 0) constructs a raw ATIF file from the agent's context window and writes it to `docs/sessions/.raw/` before running `session.save`. This is a best-effort reconstruction — the agent includes as much of the conversation as it can recall from its context, with sensitive information redacted and long tool outputs truncated.

The session-end sequence for Windsurf is: `fo-doc-audit` → `fo-session-retro` (includes Step 0: transcript save) → `fo-handoff`.

## fo-session-save skill

The `fo-session-save` skill (in `packages/forge/skills/fo/fo-session-save/`) provides intelligent annotation:

- Generates semantic `summary`, `decisions`, and `relatedArtifacts`
- Refines auto-detected `types`
- Verifies auto-extracted metadata and fixes false positives
- Updates knowledge files for self-learning across sessions

The skill reads `PREFERENCES.md` at start and no-ops if `saveSessions: false`.

## Integration with docs.archive

The `docs.archive` umbrella command includes `session.archive` in its dispatch sequence, running alongside `rfc.archive`, `adr.archive`, `plan.archive`, and `audit.archive`.
